# 奶鲸头部／头发：项目规则

更新日期：2026-10-08。范围仅限奶鲸 Live2D 头部、头发、三维参考与相应模型选型。DriveLab 及其他工程的规则不受影响。

## 1. 用户要求与当前状态

用户要求的是实际可用的现成二次元低模、动漫三渲二模型或符合二次元比例的纯白模，并明确要求不要再自行建模。用户已指出并拒绝“颅顶巨高、头发像几根香蕉挂在上边”的当前结果。

当前阶段：停止旧造型路线，审查失败并搜选现成模型。尚无用户选定并认可的替代头模／发型，不能默认采用任何候选。

“白模”只表示可以没有最终贴图，不免除二次元头脸比例、轮廓、分束和拓扑要求。通用 Stylized、欧美卡通、幼态粗胚或资产名称含 Anime，均不是符合要求的证据。

## 2. 选定之前允许与禁止的操作

允许：研究作者／官方来源；核验许可、格式与文件；下载到独立候选目录；禁用自动脚本后只读打开；统计真实网格；在不保存改变源模型的前提下调整检查视角、临时显示无纹理结构并渲染检查图。

禁止：自行重建头脸或发型；把球体、公式曲面、未匹配的曲线扫掠体当替代模型；改颅顶、改比例、雕刻、重新拓扑、拟合奶鲸、合并／替换／接入奶鲸工程；在用户没选定时先适配再汇报。不得以“技术灰模”“只是参考”绕过风格约束。

采用或适配必须先给用户看原始候选并得到选定认可。许可允许修改也不等于用户已允许本项目采用或修改。用户若只授权检查某个模型，该授权仍不包括适配。

## 3. 每个候选的最低核验内容

- 可追溯的作者／官方来源、下载入口、文件版本或哈希。
- 明确许可及限制：是否可改、商用、衍生、再分发、署名；不明就标待核实，不能直接声称可用。
- 实际格式与可打开情况。VRM、FBX、Blend、PMX 等必须对应实际获得的文件，截图不是模型。
- 实际顶点数、三角面数、材质数量；头／头发／全身统计范围分开。分别写基础网格和应用修改器后的统计，不能仅写“低模”。
- 原始正面、3⁄4、侧面、头发近景；原材质效果和无纹理结构都要实看。缺少某项就如实标明，不能凭宣传图补推断。
- 头脸检查：颅顶至眼线与眼线至下巴的比例，脸宽、额头、下颌、眼形、鼻梁／鼻尖、耳朵和侧面剪影；完整眼鼻耳不能由模糊贴图或空洞替代。
- 头发检查：是否有可编辑分层／分束，前发、侧发、后发、发根过渡和尖端是否真实存在，轮廓是否适合奶鲸；不能把几条孤立弯条当完整发型。
- 候选结论只写“符合哪些条件／不符合哪些条件／待用户选择”，不得把搜到、可下载、可冷开写成已认可。

## 4. 头型与头发的造型约束

1. 原画外层头发轮廓不能直接当作头骨／头皮轮廓。必须区分头骨、头皮、发根、发型体积和顶部呆毛，禁止为了对齐冠顶坐标拉长整个眼线上方头部。
2. 不得未经认可对现成头使用分段非等比缩放。任何未来获准的比例适配都必须先展示原始模型、适配方案和等尺度对照，说明颅顶／眼线／下巴基准。
3. 原画多尖分束、重叠层次、侧向挑尖、后发轮廓是造型内容，不能只对几条中心线。单一截面＋宽度曲线＋两端收尖得到的“香蕉体”不能冒充已匹配的奶鲸头发。
4. U 细束必须保持对应原件的路径、根部关系和投影空白；禁止用通用圆环或细钩代替。必须区分侧边 U 与顶部大环。
5. 防穿插偏移、保守深度包络和自动绑根只能作为技术手段；不能用持续前推掩盖不匹配的头型、厚度和路径。数值合法仍须逐视角检查是否悬挂、突起、过厚、离头或轮廓失真。

## 5. 两条独立验收线，不能互相代替

### 造型验收

必须先实看原模型并得到用户选定认可；任何获准适配后，再检查与奶鲸原图的正面比例、整体外轮廓、分束、重叠、尖端、侧面和三分之四面。固定视角、等尺度对照，指出每项差异。用户未确认即写“未认可”，明确拒绝即写“已拒绝”，不得写“美术通过”或笼统“通过”。

### 技术检查

记录可打开、格式、许可、规模、拓扑、绑定、遮挡、穿插、可重现等各自实测结果与边界。旧阶段的闭合、刚性随动小误差、冷开／重建通过，仅证明那些技术项。它们不能证明风格正确、头型正确、轮廓匹配或满足“不要自己建模”。

报告必须同时列“技术检查”和“造型验收”两栏／两项，即使其中一项未做。不得用“技术 PASS”代替用户认可。

## 6. 原件保护、工程阶段与交付

- 原输入、失败 `.blend`、旧 `.psd2live`、来源资产、构建源码和已交付包保留原样。修改前保存独立副本和文件哈希，不静默覆盖。
- 当前不运行旧重建或保存型刷新脚本，不继续修改失败造型。只读审计产物写入新的审计目录。
- 候选检查、三维参考、造型适配、Live2D 数据映射、真实 Core 验证分别报告。未发生的步骤不能写成已完成。
- 没有真实新 `.psd2live`／`.moc3` 及 Cubism Core 图像验证时，不称已整合 Core。Blender 渲染、网页预览或假深度不能替代真实结果。
- 本规则与 `AGENTS.md`、`AUDIT_MODEL_MISMATCH.md` 随工程备份／恢复／交接一起携带；不能只留在聊天中。工程迁移时保留内容，调整相对链接即可。
