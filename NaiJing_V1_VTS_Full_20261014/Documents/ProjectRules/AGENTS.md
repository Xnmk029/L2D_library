# 奶鲸头部／头发项目：开始工作前必读

本文件只约束奶鲸 Live2D 头部、头发及其三维参考／模型选型，不影响 DriveLab 或其他项目。完整约定见 [PROJECT_RULES.md](PROJECT_RULES.md)，实际失败审查见 [AUDIT_MODEL_MISMATCH.md](AUDIT_MODEL_MISMATCH.md)。恢复工程、复制目录或交接时必须同时携带这三个文件。

1. 用户要真实现成的二次元低模、动漫三渲二模型或符合二次元比例的白模。不得把通用欧美卡通头、幼态粗胚、高颅顶或仅有“Anime”名称的资产当成符合要求。
2. 用户已明确拒绝当前 `NaiJing_TrueSurface_HairReference.blend` 六束灰模。旧 DepthSafe 浅 Z 也未获认可。保留失败源和原交付，不覆盖，不继续修补、自建或“做完再让用户看”。
3. 当前仅可搜选现成模型、下载并只读检查、展示原始正面／3⁄4／侧面／头发近景及材质与无纹理结构。未获用户选定认可前，禁止拟合、拉伸、雕刻、合并、替换奶鲸或接入 Live2D。
4. 禁止用公式、基本体、手设中心线／扫掠截面重建替代现成动漫头发。借用一个截面预设不等于复用现成发型。禁止未经认可改变颅顶、眼线、下巴比例。
5. 候选必须核验许可、真实格式、实际顶点／三角面数、完整眼鼻耳、头发分层与外轮廓；先实看原材质和无纹理结构，不能只看宣传图或名字。
6. 技术检查与造型验收必须分别列示。无穿插、误差小、可冷开、可重建都不等于二次元风格、奶鲸比例或发型轮廓通过。造型未经用户确认一律不得写通过。
7. 先备份再做获准修改；说明工程阶段、尚未实现项和真实验证范围。没有真实 Cubism Core 结果时不得声称已整合 Core／Live2D。
8. 当前不要运行 `rebuild.sh`、`src/build_reference.py` 或会保存工程的刷新脚本。需要复核时只能在独立审计输出目录写报告，不能保存覆盖 `.blend` 或原输入。
